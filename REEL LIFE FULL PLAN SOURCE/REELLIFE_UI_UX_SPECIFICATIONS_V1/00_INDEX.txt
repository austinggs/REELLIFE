CORE PREMISE
------------
Life → Situation → Decision → Consequence → Understanding

The UI is a presentation/control layer. It reads authoritative state and issues Commands. It does not own simulation truth.

BRANCH THAT LED TO THE WORLD BIBLE
-----------------------------------
The World View / World Map requirements required a fully coherent fictional geography: planet, continents, regions, countries, settlements, spatial hierarchy, names, history, and current world state. That dependency caused the project to branch from UI/UX specification into World Design and World Build, producing the Aurelia World Bible.
