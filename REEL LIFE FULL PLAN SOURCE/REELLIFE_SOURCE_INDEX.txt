IMPORTANT
ReelLife is a clean, from-scratch implementation in the current JavaScript/TypeScript web stack.
There is no external life-simulator repository serving as the implementation base.

The repository robert1811/life-simulator is reference-only. Its architecture, source code, data,
and gameplay are not authoritative for ReelLife. Do not restore or recreate the removed stripped
starter as the project base.
