SHARED PRIMITIVES
-----------------
EntityRef — stable entity reference surviving save/load and lifecycle changes.
Money — integer minor units; never authoritative floating-point balances.
Time — timestamp/duration representation tied to the authoritative clock.
LocationRef — stable spatial reference.
EventRef — stable event reference.
Contract — parties, rights, obligations, terms, dates, and state.
Relationship — universal contextual interpersonal relationship structure.
Organization — universal organization structure.
InformationClaim — claim + source/provenance + confidence + visibility + propagation state.
Asset — economic/legal/ownership-relevant thing.
Activity — time-occupying action instance.
AuthorityCheck — actor + action + target + jurisdiction + time + context -> ALLOWED / DENIED / CONDITIONAL.
ResolutionObject — applicability + conditions + candidates + weights/probabilities + selected outcome + RNG/debug metadata.

ACTION / COMMAND MODEL
----------------------
Intent -> Command -> Validation -> Action Resolution -> Event -> Consequences -> New State

AUTHORITY / ACCESS MODEL
------------------------
actor + action + target + jurisdiction + time + role + credentials + ownership + permissions + legal status + organizational status + secrecy/access state -> allowed / denied / conditional

CORE DESIGN LAW
---------------
CONDITIONS -> DECISIONS -> EVENTS -> CONSEQUENCES -> NEW CONDITIONS
