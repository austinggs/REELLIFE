REELLIFE — SYSTEM 50: COMMUNICATION / MESSAGING
=================================================
Status: Approved architecture

ROLE
----
Models actual communication mechanisms: conversations, speech, calls, letters, email, text, DMs, broadcasts, meetings, and delivery.

OWNS
-----
- message objects
- senders/recipients
- channels
- delivery state
- timing
- responses/replies
- attachments
- visibility
- message-linked information claims
- misunderstanding/delivery outcomes

DOES NOT OWN
------------
- relationship state
- individual beliefs
- global information propagation
- personality
- UI chat rendering

MODEL / STATE
-------------
- Message includes sender, recipients, channel, time, content, visibility, delivery, reply, attachments, and linked information claims
- Process: intent -> composition -> transmission -> delivery -> perception -> interpretation -> cognition -> response

RULES / BEHAVIOR
-----------------
- Receivers can misunderstand, ignore, forget, distrust, misinterpret, delay, or respond partially
- Channels differ in speed, privacy, reach, permanence, cost, reliability, and social expectations
- Broadcast communication reaches audiences differently from private communication

SYSTEM INTERACTIONS
-------------------
- Uses Cognition for interpretation; Relationship Core for social effects; Information/Media for propagation and public reach
- NPC Decision determines communication intent and timing
- Events record meaningful communication outcomes

TESTING / QUALITY
-----------------
- Test delivery failure, misunderstanding, delayed responses, privacy boundaries, group messages, attachments, channel-specific constraints, and message persistence

SHARED ARCHITECTURAL LAWS
--------------------------
1. One authoritative owner for every persistent state field.
2. Commands express intent; events represent occurrences; consequences change state.
3. UI never directly mutates simulation state.
4. Information/knowledge is distinct from world truth.
5. Legal identity is distinct from simulation identity.
6. Organization and relationship structures are universal, not duplicated per domain.
7. Time has one authoritative clock.
8. Authoritative RNG is seeded, serialized, and reproducible.
9. Derived state remains derived.
10. Simulation resolution may change detail, never causal truth.
11. Origin influences conditions/opportunities, not destiny.
12. Legacy propagates through concrete systems, not arbitrary hidden modifiers.
13. .reel is the native persistent world/save format.

OUTCOME / CAUSALITY CHECK
--------------------------
This system must participate in the governing loop: CONDITIONS -> DECISIONS -> EVENTS -> CONSEQUENCES -> NEW CONDITIONS.

CORE PRINCIPLE
---------------
Communication transmits signals; it does not guarantee understanding.

IMPLEMENTATION NOTE
-------------------
Keep authoritative state single-owned, serializable, deterministic where configured, and separated from UI presentation. Cross-system effects should travel through Commands, Events, and explicit consequence handlers.

END OF SYSTEM SPEC
