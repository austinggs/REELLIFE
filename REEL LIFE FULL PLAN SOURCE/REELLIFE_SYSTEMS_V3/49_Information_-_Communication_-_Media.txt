REELLIFE — SYSTEM 49: INFORMATION / COMMUNICATION / MEDIA
===========================================================
Status: Approved architecture

ROLE
----
Models the information graph, news/media systems, internet/social media, propagation, audiences, and claim credibility.

OWNS
-----
- InformationClaim graph
- sources/provenance
- claim visibility/audience
- information propagation
- news/media production
- internet/social channels
- sharing/recommendation
- moderation
- corrections/disputes
- information history

DOES NOT OWN
------------
- individual beliefs
- message transport details
- reputation itself
- objective truth creation

MODEL / STATE
-------------
- Core chain: Reality -> observation -> information -> transmission -> interpretation -> belief -> behavior
- Graph nodes can be people, organizations, events, places, claims, documents, media, and messages
- Claims can be true, false, partial, misleading, outdated, uncertain, or disputed

RULES / BEHAVIOR
-----------------
- Propagation depends on network structure, source credibility, novelty, emotional relevance, visibility, incentives, platform, audience, and access
- Media can investigate, report, editorialize, err, correct, or choose audiences
- Social platforms support public/private posts, messaging, following, communities, sharing, recommendation, and moderation
- Rumors may become verified, disproven, unresolved, or forgotten

SYSTEM INTERACTIONS
-------------------
- Feeds Cognition, Reputation, Organizations, Government, Security, Relationships, and Social Systems
- System 50 handles actual communication mechanics; System 49 handles broader information flows and media behavior

TESTING / QUALITY
-----------------
- Test rumor spread, corrections, information bubbles, source disagreement, media errors, virality, moderation, private/public boundaries, and claim provenance

SHARED ARCHITECTURAL LAWS
--------------------------
1. One authoritative owner for every persistent state field.
2. Commands express intent; events represent occurrences; consequences change state.
3. UI never directly mutates simulation state.
4. Information/knowledge is distinct from world truth.
5. Legal identity is distinct from simulation identity.
6. Organization and relationship structures are universal, not duplicated per domain.
7. Time has one authoritative clock.
8. Authoritative RNG is seeded, serialized, and reproducible.
9. Derived state remains derived.
10. Simulation resolution may change detail, never causal truth.
11. Origin influences conditions/opportunities, not destiny.
12. Legacy propagates through concrete systems, not arbitrary hidden modifiers.
13. .reel is the native persistent world/save format.

OUTCOME / CAUSALITY CHECK
--------------------------
This system must participate in the governing loop: CONDITIONS -> DECISIONS -> EVENTS -> CONSEQUENCES -> NEW CONDITIONS.

CORE PRINCIPLE
---------------
The world contains more truth than any person can know, and information travels imperfectly.

IMPLEMENTATION NOTE
-------------------
Keep authoritative state single-owned, serializable, deterministic where configured, and separated from UI presentation. Cross-system effects should travel through Commands, Events, and explicit consequence handlers.

END OF SYSTEM SPEC
