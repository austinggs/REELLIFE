REELLIFE — SYSTEM 45: TRAVEL / IMMIGRATION / BORDERS
======================================================
Status: Approved architecture

ROLE
----
Models physical movement and the legal/social consequences of crossing jurisdictions or relocating.

OWNS
-----
- travel plans
- migration/relocation state
- visa/permit/residency state
- border crossings
- customs/border checks
- immigration processes
- asylum/displacement
- deportation/return processes
- temporary stays
- movement history

DOES NOT OWN
------------
- transport routes
- citizenship law definitions
- legal identity itself
- individual goals

MODEL / STATE
-------------
- Travel is physical movement; immigration is legal/social status
- Travel process: intent -> eligibility -> planning -> transport -> border -> arrival -> stay -> return/relocation
- Drivers include employment, family, education, safety, housing, income, opportunity, culture, and climate

RULES / BEHAVIOR
-----------------
- Forced displacement can arise from war, disaster, persecution, economic collapse, environmental pressure, or infrastructure failure
- Borders impose checks, delays, costs, document requirements, and jurisdictional transitions
- Temporary travel does not automatically change permanent residence/citizenship

SYSTEM INTERACTIONS
-------------------
- Uses Geography, Transportation, Legal Identity, Countries, Laws, Government, Employment, Family, Finance, Culture, Security, and Information

TESTING / QUALITY
-----------------
- Test visas, border denial, overstays, residency changes, asylum/displacement, customs, multi-country trips, and historical policy changes

SHARED ARCHITECTURAL LAWS
--------------------------
1. One authoritative owner for every persistent state field.
2. Commands express intent; events represent occurrences; consequences change state.
3. UI never directly mutates simulation state.
4. Information/knowledge is distinct from world truth.
5. Legal identity is distinct from simulation identity.
6. Organization and relationship structures are universal, not duplicated per domain.
7. Time has one authoritative clock.
8. Authoritative RNG is seeded, serialized, and reproducible.
9. Derived state remains derived.
10. Simulation resolution may change detail, never causal truth.
11. Origin influences conditions/opportunities, not destiny.
12. Legacy propagates through concrete systems, not arbitrary hidden modifiers.
13. .reel is the native persistent world/save format.

OUTCOME / CAUSALITY CHECK
--------------------------
This system must participate in the governing loop: CONDITIONS -> DECISIONS -> EVENTS -> CONSEQUENCES -> NEW CONDITIONS.

CORE PRINCIPLE
---------------
Movement is physical; immigration is legal/social status; borders are institutional constraints.

IMPLEMENTATION NOTE
-------------------
Keep authoritative state single-owned, serializable, deterministic where configured, and separated from UI presentation. Cross-system effects should travel through Commands, Events, and explicit consequence handlers.

END OF SYSTEM SPEC
