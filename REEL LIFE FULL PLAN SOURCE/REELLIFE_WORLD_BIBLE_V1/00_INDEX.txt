REELLIFE — AURELIA WORLD BIBLE V1
INDEX / PACKAGE MANIFEST
============================================================

Purpose
-------
This package contains the approved first-pass World Bible for ReelLife's fictional planet, Aurelia. It defines the world foundation and game-start conditions that the ReelLife simulation consumes.

The World Bible is content architecture, not the runtime simulation engine.

Core principle
--------------
The World Bible defines what the world is and what its starting conditions are.
The simulation determines what the world becomes.

Package rule
------------
The files are intended to be used as canonical content references. Future world expansions should preserve stable IDs, causality, geographic plausibility, demographic continuity, and the distinction between world definition and mutable world state.
